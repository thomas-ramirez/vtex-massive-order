# Documentação do VTEX Massive Orders

Bem-vindo à documentação do VTEX Massive Orders. Aqui você encontrará todas as informações necessárias para configurar e utilizar a ferramenta.

## Conteúdo

Esta documentação está dividida nas seguintes seções:

1. [**Configuração**](configuracao.md) - Como configurar a ferramenta, incluindo instruções para criar o arquivo `config.js` a partir do `config.example.js`

2. [**Funcionamento**](funcionamento.md) - Como a ferramenta funciona, detalhes sobre as APIs utilizadas e o fluxo de processamento

## Guia Rápido

Para começar a usar rapidamente:

1. Clone o repositório
2. Execute `npm install` para instalar dependências
3. Copie `config.example.js` para `config.js`
4. Edite `config.js` com suas informações específicas
5. Execute `npm start` para iniciar a criação de pedidos

## Importante

- Sempre use esta ferramenta apenas em ambientes de teste
- Nunca comite o arquivo `config.js` no repositório
- Monitore o impacto no sistema durante execuções massivas
